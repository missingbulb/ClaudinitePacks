- **Reason:** a person's pack is code that runs in their sessions, and the owner wants each person
  able to know that no non-admin edited theirs; CODEOWNERS plus a required code-owner review is the
  GitHub mechanism for that, and it holds only while every directory has its line.
- **Actor:** @missingbulb (owner).
- **Mechanism:** a world check, relevance-gated on this repo holding the store, advisory like its
  siblings because a missing line falls to the admin's `/<path>/` line and fails safe; the block is
  derived from the tree and regenerated by `write_store_codeowners.mjs` rather than kept by hand.
- **Rejected:** a check that fails any automated PR touching `<path>/` - it protects nothing once
  people have their own accounts.
- **Retire when:** GitHub can enforce per-directory ownership without a CODEOWNERS file.
